# Simulador de ventas — Remitto

Simulador que valida el endpoint de integración con el punto de venta
(RF5.3 / HU23). Ejecuta al menos cien operaciones de salida, incluye
reenvíos duplicados intencionales y compara el stock esperado con el
registrado.

Se desarrolla en el **Sprint 2**, junto con el endpoint `POST /api/v1/integracion/salidas`.
